# Healthcare-Management-System

IS321 — Healthcare Management System

Overview

A team-based C++ project developed for the IS321 — File Management and Processing course.

The system manages doctors and appointments while applying the file organization and indexing concepts covered in the assignment.

Core Requirements

* Binary file processing.
* Fixed-length records.
* Primary indexes and secondary indexes.
* Binary Search on sorted indexes.
* AVAIL LIST management.
* Add, update, delete, search, and print operations.
* Query processing for the specified assignment queries.

Technology Stack

* C++
* Git and GitHub
* Visual Studio Code
* Binary files for data storage
